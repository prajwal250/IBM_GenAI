# IBM_GenAI
AI Text-to-Image Web App Built During the IBM NASSCOM PBEL GenAI Internship (Batch #2). Features Google Sign-In, Free Image Hosting with Public Links, and a History of Prompts, Links, Generation Times and Timestamps. Runs Entirely on Free Tiers (Stability AI, ImgBB), with Endpoints Managed via Firebase. Site: https://prajwal250.github.io/IBM_GenAI/
